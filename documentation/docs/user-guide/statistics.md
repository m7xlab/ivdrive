# Statistics

Advanced analytics for drivers who want the full picture.

Open a vehicle → **Statistics**. You’ll see grouped tabs:

## Daily

| Tab | Purpose |
|-----|---------|
| **Car Overview** | Live pulse + high-level metrics |
| **Trips** | Journey list and patterns |
| **Movement** | Motion / parking behaviour |
| **Driving Stats** | Consumption and driving style |
| **Charging Stats** | Energy, cost, AC/DC mix |
| **Mileage** | Distance trends and forecast |
| **Battery SoH** | Health estimates |
| **Arrival SoC** | Predictive arrival charge |

## Analysis

| Tab | Purpose |
|-----|---------|
| **Charging Curve** | Power vs SoC |
| **Curve Integrals** | Energy delivered over session |
| **HVAC Isolation** | Climate load separated from propulsion |
| **Climate Penalty** | Weather impact on consumption |
| **Elevation** | Climb / descent effects |
| **Speed × Temp** | Efficiency matrix |
| **ICE vs EV** | Cost comparison vs combustion (TCO) |
| **Route Efficiency** | Best / worst routes |

## Live Pulse (Car Overview)

A snapshot of:

- State of charge
- Estimated full range
- Motion status
- Local weather / ambient temperature

## Date ranges

Use the **Period** picker to analyse a week, month or custom window. Most charts respect the selected range.

## Tips

1. Start with **Car Overview** after each long drive.
2. Use **Battery SoH** monthly, not daily.
3. Compare **Climate Penalty** winter vs summer to understand seasonal range.
