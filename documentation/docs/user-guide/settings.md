# Settings

Personalise units, currency, theme, security and integrations.

## Profile & units

| Setting | Options |
|---------|---------|
| **Display name** | Shown in the UI |
| **Unit system** | Metric / UK / US |
| **Currency** | EUR and others (ECB FX where available) |
| **Theme** | Light / Dark |

## Security

- **Two-factor authentication (TOTP)** — strongly recommended
- **Recovery codes** — store offline after enabling 2FA
- **Change password** — at any time
- **Sign out** — from the sidebar

## Integrations

### ABRP (A Better Route Planner)

Optional live telemetry push (SOC, charging, position).

1. Open **Settings → Integrations**
2. Connect ABRP
3. Enable what you want to share

:::note
ABRP Custom connections expose driving/charging data only — remote vehicle control is not supported (ABRP-side limitation).
:::

### AI coach

Where enabled, configure the **AI Support Coach** assistant (privacy / usage controls in Settings).

## Notifications

Control email / in-app notifications (availability depends on deployment).

## Data export

Export your data where offered in Settings (CSV / JSON depending on version).
