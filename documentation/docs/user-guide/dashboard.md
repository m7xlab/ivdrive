# Dashboard

The dashboard is your home base after signing in. It lists every connected vehicle with live status.

## What you see

| Element | Description |
|---------|-------------|
| **Vehicle card** | Photo, model, name |
| **Data health** | Freshness badge (Live / Stale / Down) |
| **Battery** | Current state of charge |
| **Range** | Estimated remaining range |
| **Odometer** | Total distance |
| **Overview / Statistics** | Jump into deep views |

## Vehicle actions

- **Refresh** — request a new poll of Škoda Connect
- **Overview** — full vehicle page (map, systems, charging)
- **Statistics** — advanced analytics suite

## Multiple vehicles

Each Connect account / vehicle appears as its own card. Switch freely; history stays separate per vehicle.

## Data freshness

| Badge | Meaning |
|-------|---------|
| **Live · just now** | Recent telemetry received |
| **Stale** | No update for a while — try Refresh |
| **Down** | Long gap — check credentials or vehicle connectivity |

See [Troubleshooting](../reference/troubleshooting.md) if a vehicle stays Stale or Down.
