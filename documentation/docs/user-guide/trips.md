# Trips & maps

Understand every drive — not just the start and end pin.

## Overview map

The vehicle **Overview** page shows the latest position and access to **Open in Maps**.

## Trips

From **Statistics → Trips** (or vehicle **Trips** tab) you can explore:

- Trip list with distance, duration and energy
- Start / end locations
- Elevation and terrain context
- Route traces on the map

## Why it matters

Longer routes, cold weather, speed and elevation all change consumption. Trip history makes those effects visible so you can plan better.

## Related analytics

| Dashboard | What it answers |
|-----------|-----------------|
| **Driving Stats** | Overall driving patterns |
| **Elevation** | Climbing penalties |
| **Speed × Temp** | How pace and weather affect efficiency |
| **Route Efficiency** | Which routes are cheapest in energy |
| **Climate Penalty** | HVAC load on consumption |

Open these from **Statistics** after selecting a vehicle.
