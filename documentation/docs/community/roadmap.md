# Roadmap

This is the **public roadmap** for iVDrive — what we ship, when, and **where we need you**.

We work closely with drivers in 2027: new metrics and new capabilities come from **real user requests** and **shared vehicle data**.

---

## Timeline

### 2026 Q1–Q4 — Built from scratch · Škoda EV beta

**Done this year** — the platform went from zero to a working beta:

| Milestone | Status |
|-----------|--------|
| Full stack from scratch (web, API, collector, DB, Docker) | Done |
| **Škoda Connect EVs end-to-end** (Enyaq iV, Elroq, …) | Live |
| Deep statistics (SoH, charging curves, penalties, cost) | Live |
| Self-hosted Docker stack | Live |
| Hosted beta at ivdrive.eu (invite-only) | Live |
| Product site + documentation | Live |
| **ABRP live telemetry** | **Just shipped** |

### 2027 Q1–Q2 — Volkswagen fully electric (BEV)

- First-class **Volkswagen battery-electric** support
- Starts with the **ID. family** (ID.3, ID.4, ID.5, ID.7, …); other fully electric VW models where Connect APIs allow
- Same trip / charging / battery analytics as Škoda
- Petrol / diesel VWs are **out of scope**

### 2027 Q3–Q4 — SEAT fully electric (BEV)

- **SEAT / CUPRA battery-electric** vehicles (Mii Electric, Born, Tavascan, and other SEAT EVs as APIs allow)
- **Electric only** — not the full SEAT petrol lineup
- Shared learnings from VW Group APIs
- Continuous **analytics upgrades all through 2027** (user-driven metrics)

### 2028 Q1–Q2 — Hybrids & PHEVs (fuel + electric together)

- **Škoda, VW, SEAT hybrid / plug-in hybrid** capabilities
- Combined **fuel + electric** consumption, cost and efficiency views
- Unified “what did this journey really cost?” reporting

### All of 2027 — always on

- Improving analytics with the community
- New metrics from **user requests**
- Faster data quality, smarter alerts, better exports

## We need contributors with real cars

**This roadmap only works if owners share vehicle data and feedback.**

If you drive a **Volkswagen**, **SEAT / CUPRA**, or another **VW Group** EV (or PHEV), we especially need you:

- Join the beta and connect your car (data stays in your account / your self-hosted stack)
- Tell us which metrics you want next
- Help validate charge curves, SoH and trip energy on **your** model

**Want to help unlock a brand?**  
Open a [Discussion](https://github.com/m7xlab/iVDrive/discussions) or [Issue](https://github.com/m7xlab/iVDrive/issues) with your **model + year** — or sponsor the project so we can buy access and test hardware.

:::note
Self-hosted users can contribute anonymised insights or run private previews without publishing personal trips.
:::
