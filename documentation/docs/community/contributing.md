# Contributing

Contributions are welcome — code, docs, bug reports and ideas.

## Ways to help

- Report bugs with clear reproduction steps
- Improve documentation
- Add tests
- Implement features from the roadmap
- Share EV data insights that should be new dashboards

## Development setup

1. Clone the repo: `git clone https://github.com/m7xlab/iVDrive.git`
2. Follow the self-hosting guide for local Docker
3. For frontend work: `cd frontend && npm install && npm run dev`
4. For backend work: run the API container or a local venv against compose dependencies

See `CONTRIBUTING.md` in the repository for coding standards and PR process.

## Pull requests

- Keep changes focused
- Describe **why**, not just what
- Include screenshots for UI changes
- Update docs when behaviour changes

## Code of conduct

Please read `CODE_OF_CONDUCT.md`. Be kind and constructive.

## Security

Never file public issues for vulnerabilities. Follow `SECURITY.md`.
