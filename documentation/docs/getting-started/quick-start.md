# Quick start

Get from zero to a live dashboard in a few minutes (hosted beta).

## 1. Request an invite

1. Open [ivdrive.eu/register](https://ivdrive.eu/register)
2. Enter your email and join the waitlist
3. When approved, you receive an invite email

## 2. Verify and register

1. Click the **verify** link in the email
2. Choose a display name and password
3. (Optional but recommended) Enable **two-factor authentication** later in Settings

## 3. Add your vehicle

1. Open **Add vehicle** in the dashboard
2. Sign in with your **Škoda Connect** credentials
3. Wait for the first sync — trips, charging and battery data appear automatically

:::tip
Use a dedicated Škoda Connect account if you prefer not to store your main password. Credentials are encrypted at rest in the deployment you use.
:::

## 4. Explore

Once data is in, try these first:

| Section | What to look at |
|---------|-----------------|
| **Overview** | Live battery, range, charging state |
| **Trips** | Recent drives and efficiency |
| **Charging** | Session history and curves |
| **Statistics** | SoH, vampire drain, cost estimates |
| **Settings** | Units, currency, theme, integrations |
